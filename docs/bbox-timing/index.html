How these probabilities are calculated

At each New York checkpoint, the denominator is the set of matching historical nights when the target was still pending. The numerator is the subset that breached the target in the remaining time. A touch at the same price leaves the target pending. For either edge, the first edge reached finishes the event. For both edges, the second edge reached finishes it.

Each window includes the five-minute candle ending at its deadline. A signal becomes known when its five-minute candle completes. A BBOX window that opens past the selected edge has breached it at the opening print. “Holds” means the selected evening price is never exceeded in the specified direction through 08:30.

Prior-window edge tags count any qualifying wick, including one from an ongoing move outside. A return requires a completed five-minute close at or between the BBOX edges. The first breach candle can itself close back inside. A fresh breach needs a subsequent candle that trades beyond the same edge.

Prior NY BBOX uses the same-contract 09:30–16:00 high and low. Rates use complete nights from January 2022 to October 15, 2026. Small samples are marked below 30 cases. The intervals are 95% Wilson reference intervals. These rates describe historical price events. A trading result also depends on entry, adverse movement, and execution.
