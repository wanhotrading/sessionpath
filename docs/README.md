# SessionPath.By LUI

Static CL and NQ research and forecast website.

Publish with GitHub Pages from `main` → `/ (root)`. The `.nojekyll` file preserves the prebuilt site.

AI chart-reading endpoints are unavailable on this static deployment. Manual inputs and browser-local import features remain available. No server credentials or private environment files are included.

Research results are historical frequencies, not guarantees of future performance.
