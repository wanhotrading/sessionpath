What the new readings measure

The original Mean forecast boxes retain their existing calculations. These follow-up readings describe specific events after a completed observation.

Next-window running-extreme continuation

At05:00, classify the04:55–05:00 candle close relative to the03:00–05:00 Mean box. Freeze the actual running high and low since the preceding19:30. Measure whether05:00–08:30 makes a strict new high, a strict new low, both, or neither. At08:30 repeat using the05:00–08:30 Mean box and follow price through16:00. Equal touches do not qualify; one tick beyond does.

After the first breach

Only the first candle with a strict high/low breach of either Mean boundary qualifies. Observe after that five-minute candle closes. A wick-only breach has already closed inside and cannot count as a subsequent return. If its first candle breaches both sides, intrabar order is unknown and side-specific estimates are unavailable.

A return means an inclusive completed close back inside during the next four five-minute candles. All four candles must fit before the original window ends. A future1.20× or1.30× hit uses a later candle's high/low touch. Targets already reached in the signal candle are excluded from that future-target estimate.

For a lower extreme89 and upper extreme91, width W=2. Upward1.20× is89+1.20×2=91.40; downward1.20× is91−1.20×2=88.60.

Of96 primary single-filter comparisons, two timing tests passed the specified screen: CL03:00–05:00 future1.30× and NQ08:30–16:00 future1.20×. These are the only automatic half-hour adjustments in this release. The NQ result is more sensitive to the uncertainty method's block length.

Other displayed estimates use the same-market/window/side/wick-or-close baseline. Closing overshoot is promising for20-minute returns, but no return-filter test passed the full adjusted screen. Its optional experimental view is off by default and cannot export an indicator code.

Counts, smoothing and uncertainty

The broad baseline is (earlier successes+1)/(earlier eligible observations+2). An approved categorical adjustment or endpoint state uses (local successes+20×baseline)/(local observations+20). A sparse local group moves toward the broader history. The observed k/n and Wilson95% reference interval belong to the raw group; they are not an interval around the smoothed displayed number.

Chronological evaluation uses earlier dates only. First-breach evaluation starts2024 with at least50 earlier eligible observations; endpoint evaluation uses at least100. Paired uncertainty resamples blocks of trading dates, with10-date blocks and3,000 repetitions as the primary check;5/20-date sensitivities and multiple-test adjustment are reported in the original studies. This is explored retrospective history, not an untouched future holdout.

Website and indicator responsibilities

The website selects earlier observations, calculates probabilities and exports an SR1 research code. TradingView validates the coded market, observation date, window, Mean edges, first-side/type or endpoint state, and frozen reference against its completed candles before showing a verified reference. It then tracks actual reached/unreached or return outcomes. The percentage remains the historical estimate made at first observation; it is not continuously refitted as time passes.

Research snapshots SEP1 and SFB1 can be copied from Pine Logs into the website. There is no automatic chart-to-website connection. Original forecast and BBOX return codes retain their own separate inputs. Current custom tags or NY cohort filters do not refit the new study benchmarks; the NY first-breach reference uses Own Wide Mean.
