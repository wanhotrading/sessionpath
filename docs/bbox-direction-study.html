The live remaining-chance curve

Keep the original group and deadline D fixed. At time t, exclude every historical case whose first return already occurred at or before t. Remaining probability = cases with t < first return ≤ D / cases with first return > t or no return through 08:30. Zeros remain in the denominator. This curve is conditional on your confirmation that your actual trade has not returned; the clock does not read price.

Live tracking uses the exact most recently completed five-minute observation, avoiding later observations from the same half-hour block. The legacy half-hour view remains available. Results advance at five-minute closes, not every second; NY clock uses America/New_York including daylight saving. The curve ends at the deadline. Future points assume no intervening return.
